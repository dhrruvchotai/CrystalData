# CrystalData

**CrystalData** is a tool designed to make data pre-processing for machine learning simple and efficient. With CrystalData, you can upload a CSV file, clean raw data, generate detailed statistics, handle missing values, remove duplicates, detect outliers, perform train-test splits, and prepare datasets for ML pipelines—all with minimal effort.

CrystalData is ideal for data scientists, students, and anyone working with CSV datasets who wants to streamline their data preparation workflow.

---

## Features

- **Data Cleaning**: Handle missing values, duplicates, incorrect formats, and more.  
- **Data Profiling**: Generate detailed summary statistics, distributions, and correlations.  
- **Pre-processing for ML**: Scale and encode data, detect and remove outliers, smooth data.  
- **Train-Test Split**: Split your dataset into training and testing sets for model evaluation.  
- **Pipeline Support**: Download ready-to-use scikit-learn pipelines.  
- **CSV Input/Output**: Easy integration with existing workflows.

## Getting Started

Follow these steps to get **CrystalData** running on your machine.

### Prerequisites

- Python 3.8 or higher  
- `pip` (Python package manager)  
- Optional but recommended: Virtual environment (`venv` or `conda`)  

Check Python and pip versions:

```bash
python --version
pip --version
```
Clone the repository and Set branch: 
```
git clone https://github.com/dhrruvchotai/CrystalData.git
cd CrystalData
git checkout version1.0
```

Create a virtual environment:
```
python -m venv venv
# Activate the environment
  # Linux/macOS
    source venv/bin/activate
  # Windows
    venv\Scripts\activate
```

Install dependencies:
```
pip install -r requirements.txt
```
